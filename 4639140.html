WorkBuddy 快速接入 Suno 服务，Suno V6 创作指南

作者 崔庆才 发表于 2026-10-13 分类于 技术教程 阅读次数： 本文字数： 3.2k 阅读时长 ≈ 3 分钟
本文介绍如果让 WorkBuddy 快速接入 Ace Data Cloud的 Suno 服务，并使用 Suno V6 创作歌曲。

WorkBuddy 当前内置的连接器还无法覆盖 GPT Image 2、Suno 音乐创作和 Google 搜索等功能。如果需要使用这些服务，可以接入 Ace Data Cloud 提供的 MCP 服务。

整个接入过程主要分为两个步骤：

  1. 在 Ace Data Cloud 控制台中获取平台 API Key。
  2. 在 WorkBuddy 中配置 MCP 服务。

本文将介绍如何在 WorkBuddy 中接入 Ace Data Cloud 的 MCP 服务，并以调用 Suno 模型生成歌曲为例，演示服务的具体使用方法。

安全提示：请妥善保管平台 API Key，不要将其发布到文章、截图、公开仓库或聊天记录中。如果平台 API Key 已经泄露，请立即在控制台中撤销并重新创建。

1. 获取 Ace Data Cloud 平台 API Key

打开 Ace Data Cloud 控制台：

Ace Data Cloud 控制台直达链接

进入控制台后，复制需要使用的平台 API Key。

如果还没有平台 API Key，请点击页面右上角的创建按钮，按照提示创建一个新的平台 API Key。

2. 在 WorkBuddy 中配置 MCP 服务

WorkBuddy 提供了三种 MCP 服务配置方式，任选一种即可：

  1. 通过 MCP 管理器配置；
  2. 直接编辑配置文件；
  3. 让 WorkBuddy 自动完成配置。

方法一：通过 MCP 管理器配置

打开 WorkBuddy，依次进入专家 > 技能 > 连接器页面。

这里提供了多个可用的连接器。点击页面右上角的自定义连接器，进入连接器配置页面。

此时会显示连接器配置弹窗。下面以 Ace Data Cloud 的 Suno 服务为例，演示具体的配置方法。

点击页面顶部的添加 MCP按钮。

首次使用时，WorkBuddy 可能会要求你确认是否信任该服务。点击信任按钮后，即可查看 Suno 提供的相关服务。

至此，你就可以在 WorkBuddy 中调用 Ace Data Cloud 提供的 Suno 服务了。

总结

通过 Ace Data Cloud 提供的 MCP 服务，可以方便地为 WorkBuddy 扩展 Suno 等外部能力。

整个接入过程主要包括以下两个步骤：

  1. 在 Ace Data Cloud 控制台中创建并复制 API Key；
  2. 在 WorkBuddy 中添加 MCP 配置，并完成服务授权。

本文以 Suno 音乐生成为例，演示了 MCP 服务的配置、调用及任务查询流程。其他 MCP 服务也可以采用类似方式接入。

Ace Data Cloud 的 Suno 服务采用按次计费模式，无需订阅包月套餐。实际收费标准请以 Ace Data Cloud 控制台和相关技术文档中的最新说明为准。
