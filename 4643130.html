从零搭建自己的 AI Studio：建站、品牌、定价和独立域名一次讲清楚

作者 崔庆才 发表于 2026-11-01 分类于 技术教程 阅读次数： 本文字数： 4.4k 阅读时长 ≈ 4 分钟
从创建 Studio 子站开始，完整讲清品牌设置、登录方式、能力管理、价格配置、自定义域名和上线检查。

很多人想做一个自己的 AI 工具站，真正动手时却很容易卡住。

站点从哪里创建？Logo 在哪里换？哪些工具该开放？价格怎么加？独立域名又该怎么解析？

这些事情拆开看都不难，难的是后台入口比较多，第一次操作时不知道先做什么。最省事的顺序，其实就是先把子站创建出来，确认能正常访问，再处理品牌、登录、功能、价格和域名。

这篇文章就按这个顺序走一遍。做完以后，你会得到一个可以正常打开、带有自己品牌、可以让客户登录和使用工具的 Studio 站点。

先看看 Studio 做出来是什么样

Studio 是一个直接在浏览器里使用的 AI 创作平台。首页通常会展示聊天、图片、视频和音乐等工具。用户点开分类后，可以查看工具介绍，再进入对应的创作页面。

首页不只是工具列表，也可以展示一些精选作品。用户看到喜欢的效果后，点“创建同款”就能进入对应工具，再根据自己的需求调整素材和参数。

这里有一点需要提前说清楚：创建同款只是把用户带到对应的工作区，并不是点一下就直接生成。用户仍然需要检查素材、提示词和生成参数。

先把子站创建出来

打开 Studio 网页版，登录以后点右上角头像，进入“设置”，找到“我的子站”，然后点击“创建子站”。

“我的子站”在 Studio 官方主站的网页版里。如果你正在使用 App，或者已经进入某个白牌子站，就有可能看不到这个入口。

创建前最好先准备两样东西：一个给客户看的站点名称，以及一个简短的英文前缀。

比如站点叫“星河创作”，前缀可以填写 xinghe。创建完成后，系统会分配一个类似 xinghe.studio.acedata.cloud 的地址。

前缀只填写前面那一小段，不要把 .studio.acedata.cloud 再写进去。它支持小写字母、数字和短横线，长度为 3 至 32 个字符，开头和结尾需要是字母或数字，也不要连续使用短横线。

站点标题就是客户实际看到的品牌名称，后面还可以修改，所以第一次不用在这里纠结太久。

如果提示前缀已经被占用，换一个就行。创建成功后，新的子站会出现在列表里。

列表里的“打开”和“管理”用途不同。

“打开”是进入客户看到的网站，可以用它检查首页、登录入口和移动端显示是否正常。“管理”则是进入站点后台，后面换 Logo、改价格、选工具和绑定域名，都在这里完成。

刚创建完，先不要急着改一堆设置。把系统分配的地址复制出来，用浏览器无痕窗口打开一次。确认首页能显示、登录按钮能点，“管理”也进入了正确的子站，这一步就算稳了。

把默认页面换成自己的品牌

子站可以打开以后，就可以开始处理品牌。

进入“我的子站”，找到刚创建的网站，点击“管理”，然后打开“站点设置”。这里可以修改站点名称，上传 Logo 和 Favicon，还可以设置主题颜色、网站语言和客服信息。

Logo 是页面中展示的品牌图片，Favicon 是浏览器标签页上的小图标。它们需要分别上传，不能只换 Logo 就以为浏览器图标也会跟着变。

如果保存后仍然看到旧图标，可以换无痕窗口或另一台设备再看一次，浏览器缓存有时不会立即更新。

继续往下可以看到主色调和语言设置。

主色调会影响按钮、链接和页面里的高亮颜色，尽量选择和 Logo 搭配的颜色。

“网站语言”决定访客可以切换哪些语言。“强制语言”则是让所有访客统一使用某一种语言。如果希望网站根据访问者的浏览器自动选择语言，保留“自动检测”会更合适。

客服信息也建议在这里补齐，而且要填写真正有人回复的联系方式。保存后用未登录状态打开一次，确认普通访客同样能找到客服入口。

给网站写一句让人看得懂的介绍

品牌外观调整好以后，进入“SEO 设置”。

这里不用堆一长串模型名字。真正重要的是让人一眼看懂这个网站面向谁，能帮他做什么。

如果你的客户主要是自媒体创作者，可以这样写：

为自媒体创作者提供 AI 写作、文章配图和短视频制作工具，在一个网站内完成日常内容准备。

关键词也围绕实际业务填写就行，比如“AI 写作”“文章配图”“短视频制作”。不要把几十个模型名称全部塞进去，那样看起来信息很多，实际上不容易让客户理解。

把登录方式调通

网站能看只是开始，客户还要能够正常登录。

进入“Authentication”或者“认证设置”，打开准备支持的登录方式，再从已经启用的方式里选择一个默认选项。登录方式至少要保留一种，不能全部关闭。

下面还可以调整登录模式。比如“嵌入式弹窗”会直接在当前网站内弹出登录页面，而默认登录方式决定弹窗打开后优先展示邮箱、手机号还是其他入口。

保存以后，一定要用无痕窗口完整登录一次。检查登录是否成功，以及完成后是不是回到了自己的子站。

登录过程中暂时跳到统一认证域名并不一定是故障。真正需要确认的是登录完成后能否回到子站，账号状态是否正常。

不要一开始就把所有工具都摆出来

接下来进入“Capabilities”，也就是能力设置。

这里决定客户在网站上能看到哪些 AI 工具。比较实用的做法，是先围绕一个明确场景开放工具。

如果你的客户主要做图文内容，可以先开放写作和图片生成；如果客户确实有视频和音乐需求，再逐步加上。工具入口少一点，客户反而更容易知道该点哪里。

右侧的编辑入口可以修改工具在当前子站中的显示名称和图标。

名称可以改得更容易理解，比如把内部模型名称改成“文案助手”或“图片生成”。不过要注意，修改名称只会改变页面展示，不会把底层模型变成另一个模型，也不会改变实际调用方式和计费。

图标支持 PNG、JPEG 和 WebP，上传后会按正方形裁切。需要透明背景时，可以优先使用透明 PNG。

保存以后，再从客户视角打开首页，看看常用工具是否容易找到，不准备提供的入口有没有被隐藏。

这里的开关主要控制页面展示。把入口藏起来，不等于修改了客户的 API 权限，两者不要混在一起理解。

首页场景不用照搬默认内容

在“首页设置”里的“创作场景”中，可以修改默认场景的名称、介绍、封面和排列顺序，也可以给每个场景重新选择推荐工具。

比如你准备做一个自媒体工具站，可以把首页整理成“写文章”“做配图”“剪短视频”“制作配乐”。客户看到的是自己熟悉的工作，而不是一堆陌生模型名。

新建场景后先保存，再打开自动翻译。封面直接使用上传或替换按钮即可，不需要自己粘贴图片链接。

暂时不提供的工具不要放进推荐场景，否则用户点进去才发现不能使用，会比一开始看不到更让人困惑。

价格先定一个统一规则

进入“Price”或者“价格设置”，先设置全站统一的加价比例。

大部分服务可以直接继承这个比例。如果某个工具成本、售后压力或者市场价格不同，再单独给它设置覆盖规则。

假设某项服务的平台价格是 100，全站加价为 10%，客户看到的价格就是 110。

如果这个服务又单独设置了 5%，最终使用的是单项服务的 5%，价格是 105，而不是先加 10% 再加 5%。

需要单独设置时，在服务自定义区域点击添加，选中服务，再填写加价比例。

单项加价留空，表示继续使用全站比例；填写 0，表示不加价，但不代表免费。

这里还可以调整服务名称、介绍、排序和可见状态。改完以后，不要只在后台看，最好打开客户页面，分别找一个继承全站价格的服务和一个单独设置价格的服务，看看最终结算页是否符合预期。

“关闭充值”只是隐藏子站里的充值入口，不会清空已有余额，也不是消费上限。只有明确不想让客户从子站购买时，才需要打开这个选项。

实际生成图片、音乐或视频会产生费用。上线验收时先看价格，再做一个小任务测试，没有必要一上来批量生成。

有明确内容时再放首页 Banner

首页 Banner 不是必须项。

如果暂时没有活动、主推服务或者清楚的落地页面，宁愿先留空，也不要随便放一张图占位置。

需要添加时，可以填写图片、标题、副标题、跳转地址和展示时间。

如果 Banner 推广的是文章配图，就应该直接跳到对应工具，而不是又把用户带回首页。

站内地址通常可以填写以 / 开头的路径，也可以填写完整的 HTTP 或 HTTPS 链接。留空时，Banner 只展示，不能点击。

保存以后亲自点一次，确认跳转页面没有填错。

最后再绑定自己的域名

系统分配的地址可以正常打开以后，再处理独立域名。

进入“我的子站”，点击“管理”，找到“Custom Domain”或者“自定义域名”。填写完整域名，例如 studio.example.com，不要加 https://，不要填写页面路径，末尾也不要加斜杠。

提交绑定后，页面会给出一个 CNAME 目标地址，把它复制下来。

接着进入购买域名的平台，打开 DNS 解析管理。

如果绑定的是 studio.example.com，记录类型选择 CNAME，主机记录通常填写 studio，记录值填写 Studio 后台刚刚提供的 CNAME 目标，TTL 保留默认值即可。

不同域名服务商的界面可能不一样。有些要求填写前缀，有些会提示填写完整域名，按照页面说明操作就行。

如果 studio 这个名字已经存在 A、AAAA 或其他 CNAME 记录，先确认它是不是被别的网站使用。不要为了绑定新站，直接删除正在使用的解析记录。拿不准时，换一个没有使用过的子域名更安全。

DNS 保存后，回到 Studio 的自定义域名页面刷新或验证状态。

DNS 更新和 HTTPS 证书签发是两个过程，不一定会同时完成，也没有一个绝对固定的等待时间。后台显示上线以后，还要亲自使用 https:// 打开网站，确认浏览器没有证书警告。

上线前别只看首页

网站能打开，并不代表所有地方都没有问题。

用电脑和手机分别访问一次，看看站点名称、Logo、图标和导航有没有错位。随便打开一个内部页面再刷新，确认不会跳到 404。退出账号后重新登录，检查完成后能不能回到自己的域名。

常用工具、客服入口和价格页面也要走一遍。如果准备测试支付或生成任务，先确认价格，再做小额测试。

最后再看一下移动端。

手机端重点看站点标题是否完整、按钮能不能正常点击、底部导航是否清楚。很多站点在电脑上没问题，到了手机上才会发现名称太长或者入口不好找。

如果系统域名也打不开，先检查子站本身，不要急着折腾 DNS。

如果只有自己的域名打不开，就检查域名有没有填写完整、解析记录有没有冲突，以及公共 DNS 是否已经更新。

如果浏览器提示连接不安全，先确认解析是否正确，再查看证书状态，不要让客户忽略警告继续访问。

至于分享链接时仍然出现平台默认名称，有可能是分享工具没有执行网页脚本。这和域名绑定失败不是一回事，需要分开排查。

做到这里，网站就可以开始用了

一个能正式对外使用的 Studio，不是只换个 Logo 就结束了。

客户需要能够打开网站，看懂这里是做什么的，找到合适的工具，顺利登录，看到合理的价格，遇到问题还能联系到你。独立域名则是最后那层门面，让整个网站真正像自己的产品。

最稳妥的做法，就是每改完一块，都切回客户视角看一次。后台保存成功不代表前台一定符合预期，无痕窗口、手机和独立域名都亲自走一遍，通常就能在上线前发现大部分问题。
