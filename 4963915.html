在 WorkBuddy 中接入 GPT Image 2.5：配置、生成与编辑实测

作者 崔庆才 发表于 2026-10-09 分类于 产品推荐 阅读次数： 本文字数： 2.4k 阅读时长 ≈ 2 分钟
从添加 MCP 连接器、配置 API Key，到调用 GPT Image 2.5 生成和修改图片，本文完整演示如何增强 WorkBuddy 的 AI 图片创作能力。

WorkBuddy 虽然有腾讯的图片生成模型，但是效果还是比不上 GPT Image 2.5 、Seedream、Nano Banana 2 等图片生成模型，所以，如果需要在工作中，无缝调用这些图片生成模型，那么你需要接入 Ace Data Cloud 提供的 MCP 服务即可。
本文将介绍如何接入 Ace Data Cloud 的 OpenAI MCP 服务，并调用 GPT Image 2.5，以及并通过实际案例测试其图片生成与编辑能力。

由于 GPT Image 2.5 通过 OpenAI 接口调用，因此需要接入 Ace Data Cloud 的 OpenAI MCP 服务。所以这个模型的接入需要接入 OpenAI 相关的接口。

1. 配置 WorkBuddy MCP 连接器

WorkBuddy 的 MCP 连接器在专家-技能-连接器选项中的连接器，然后点击右上角的自定义连接器。

打开自定义连接器窗口

点击 添加 MCP 按钮，切换到编辑模式。

在编辑器模式下，编辑 MCP 配置 JSON，也可以点击界面中的配置文件入口，直接编辑对应的 JSON 文件。

5. 总结

本文为你介绍了如何接入 GPT Image 2.5 ，以及测试了图片生成和修改的案例，如果需要工作中使用，那么我还是建议使用 Ace Data Cloud 的 GPT Image 图片生成，以为这个是目前最经济实惠和最先进的模型，可以免去你很多因为调试的时间。
