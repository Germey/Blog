3分钟搭好属于自己的 AI Studio 网站：自己用，也能分享赚佣金，后端和售后服务交给我们

作者 崔庆才 发表于 2026-10-03 分类于 技术教程 阅读次数： 本文字数： 5k 阅读时长 ≈ 5 分钟
这是一个教程，教你如何注册和创建自己的AI Studio网站，然后了解我们的共创联盟，这个AI站不仅仅可以你自己使用，也可以分享给朋友使用，获取一些佣金的收益。AI网站的后端和售后服务完全由我们来提供。

想做一个自己的 AI 网站，是不是得先买服务器、找人写代码，再研究怎么接模型？

如果是从头开发，确实有不少事情要处理。不过，只是想拥有一个挂着自己品牌、能让大家直接使用 AI 的网站，还有一种省事的做法：创建一个 AceData Cloud Studio 分站。

我们平台提供现成的产品和底层 AI 服务，你来设置名字、挑选工具、整理首页，再把网站分享给需要的人。不必先从零开发整套系统。

这篇就带你把它做出来。先完成两件事：

  1. 注册账号，了解创收联盟和自己的推广信息。
  2. 创建 Studio 分站，拿到一个可以打开的网址。

名字、Logo、价格和自己的域名，都可以在站点建好之后慢慢配置。

先说清楚：“两步”说的是基础起步，不是两次点击就完成所有运营工作。网站建好后可以自己使用，也可以分享给别人；这个就是我们一直在努力打造的共创联盟，当有更多的客户的时候，我们的服务也可以做的更好。

一、先看看，Ace Data Cloud Studio 能做什么？

可以把 Studio 理解成一个放在浏览器里的 AI Agent 工具箱。

想写点东西、做张图片，或者试着创作音乐和视频，都可以在这里找到对应工具，不需要写代码。具体可用工具以当前页面为准。

你想做的事 可以怎么用
写文案、整理资料 让聊天工具帮你列思路、修改表达、翻译或总结
做封面、商品配图 输入画面要求，或用支持编辑的工具调整图片
创作歌曲 在相应音乐工具中提供主题、风格或歌词
制作视频素材 用支持的工具，根据文字或图片生成视频

不用一上来就记住所有模型名称，先想好自己要做什么，再选工具就行。

下面是官方 Studio 的首页示例。左侧集成了大量最前沿的模型和功能模块，比如OpenAi 的GPt模型，Anthropic的模型，和Gemini，以及GPT image2.5,和大名鼎鼎的音乐创作工具，SUNO V6我们都可以轻轻松松的对接。

分站和这个 Studio 是什么关系？

简单说，你不用重新做一套工具，而是在现成产品上配置自己的品牌入口：网站叫什么、用什么 Logo、推荐哪些功能、客户到哪里找你，都可以按自己的需要整理。底层 AI 服务由平台提供。

比如，你平时主要帮别人做文章配图，就可以先把图片相关工具介绍清楚。没有必要为了显得功能多，把自己都没用过的工具全部摆出来。

另外，有了自己的分站，不代表 AI 调用免费。实际生成任务仍可能产生费用，使用前要看对应服务的价格。

产品能力可参考：Studio 产品与推广说明、白牌平台总览。

二、第一步：注册账号，了解创收联盟

先把名字说清楚：官方文档里叫 “创收联盟”。它提供两种参与方式：

  • 直接推广平台：分享自己的邀请链接，推荐别人使用官方 Studio 或 API Platform。
  • 经营自己的白牌站：用自己的品牌入口提供服务，客户的有效订单按现行分销规则参与结算。

这两种方式不冲突。你可以先体验产品、分享教程，熟悉之后再创建分站。

1. 注册并登录 Studio

打开 Studio 官方网站，注册或登录账号。

建议先用自己感兴趣的工具做一个小任务。比如整理一段文案，或者在确认费用后生成一张图片。自己走过一遍，后面给别人介绍时会更有底。

2. 打开分销页，找到自己的推广信息

登录后进入 Studio 分销页。

在这里可以找到自己的推荐链接和二维码，也可以查看邀请用户、累计返佣和当前比例等信息。直接复制自己后台的链接，不要手动改用户 ID。

下面是官方教程中的历史账户截图，只用来帮助你识别页面。图里的收益不是预期收入，链接和二维码也不是你的。

复制完成后，建议在无痕窗口打开一次；如果准备用二维码分享，也先拿手机扫一下，确认入口正确。

3. 创建分站前，需要先买一个套餐吗？

不需要，注册就可以了，国内的朋友需要实名认证。

到管理后端在左侧的列表中选择站点管理，就可以到分站管理模块了。

详细说明：创收联盟总览、Studio 推广操作教程。

三、第二步：创建分站，再把它改成自己的样子

1. 找到“我的分站”

在 Studio 官方网页版登录后，点击用户头像，依次打开：

Settings（设置）→ My Subsites（我的分站）→ Create Subsite（创建分站）。

找不到的话，先检查自己打开的是不是官方网页版。这个入口不会出现在原生 App 或其他分站里。

2. 填一个名字，再选一个网址前缀

创建时，主要填两项：

要填什么 示例 说明
分站标题 小林 AI 工作室 客户看到的网站名称，之后还能修改
子域名前缀 xiaolinai 系统网址前面的一段

前缀需要使用 3～32 位小写字母、数字或连字符，不能以连字符开头、结尾，也不能出现连续连字符；还需要避开保留名称和已被占用的前缀。右侧的 .studio.acedata.cloud 由系统补上，不要重复填写。

点击确认，等成功提示和列表刷新。新站点出现在列表里，这一步就完成了。

这里有两个按钮，别弄混：

  • 打开：看客户会看到的网站。
  • 管理：修改这个分站的配置。

先点“打开”，再把网址复制到无痕窗口里，看看首页和登录入口能不能正常显示。

到这里，基础建站就完成了。下面这些配置，可以按自己的需要逐项做，不必一次填完。

3. 换上自己的名字、Logo 和客服入口

从分站列表点击“管理”，进入 站点设置。

先处理四样东西：站点名称、页面上的 Logo、浏览器标签上的 Favicon，以及客户能联系到你的客服入口。

Logo 和 Favicon 是两个位置，需要分别设置。页面标题和图片旁的铅笔图标，就是编辑入口。

继续往下，还可以设置品牌色、可选语言和强制语言。想让访客自行选择语言，就别误开“强制语言”。

网站介绍不用写得很大。一句让人听得懂的话就够了，例如：

给内容创作者准备的 AI 工具站，写文案、做配图，有问题可以联系我。

再去“认证”里保留至少一种可用的登录方式，保存后从无痕窗口试着登录一次，确认能回到自己的分站。

4. 挑工具，整理首页

打开 Capabilities（能力），选择你准备提供的工具。暂时不做的，可以先关闭展示入口。

第一版不妨先围绕一个用途来做。比如，主要面向自媒体用户，就先讲清楚写作和图片；主要面向音乐爱好者，就先把音乐工具的使用说明做好。

想进一步整理首页，可以进入 首页设置 → 创作场景，调整场景名称、说明、封面、顺序，以及场景下推荐的工具。

这里顺便提醒一句：关闭展示入口只是让它不出现在相应位置，不等于撤销客户的 API 调用权限。

5. 设置价格：先统一，再处理例外

进入 Price（价格），可以设置整站加价比例；如果某项服务需要单独定价，再增加单服务覆盖。

单服务比例优先，不会和整站比例叠加。单服务加价留空表示继承整站设置，填 0 表示不加价，不是免费。

举个好理解的例子：假设平台价格是 100，整站加价 10%，渠道价就是 110；如果这个服务单独加价 5%，渠道价则是 105。实际支付价格要去结算页核对。

不过，这个加价不是你的佣金比例，收益怎么计算，后面单独讲。

6. 进阶设置：绑定自己的域名

系统网址能用了，再考虑换成自己的地址，比如 ai.example.com。

你需要先有一个域名，并且能登录它的 DNS 管理后台。然后从 我的分站 → 管理 → 自定义域名 进入绑定页面。

按这个顺序操作：

  1. 填写完整域名，例如 ai.example.com，不要带 https://、路径或末尾斜杠。
  2. 点击绑定，复制页面给出的 CNAME 目标。
  3. 去域名服务商的 DNS 控制台，添加解析。
  4. 回到 Studio，按页面提供的操作验证或刷新状态。
  5. 等 DNS 和 HTTPS 都就绪后，再打开自己的正式网址。

通常可以这样填写解析：

字段 示例
记录类型 CNAME
主机记录 ai，具体按域名服务商要求
记录值 从你自己的 Studio 控制台复制
TTL 先用服务商默认值

不要照抄截图中的 CNAME，也别为了新站随手删除旧业务的解析记录。同名记录已有用途时，先确认，或者换一个没用过的子域名。DNS 更新和证书签发都需要时间，不能保证固定几分钟完成。

最后，用电脑和手机各检查一次：

  • 首页能打开，标题和 Logo 正确；
  • 打开内部页面后刷新，不报错；
  • 登录后能回到自己的站；
  • 主推工具和客服入口能打开；
  • 价格、条款和隐私说明已经核对。

需要对照操作时，可以分别查看：创建分站、品牌与登录、功能与价格、自定义域名。

四、网站做好了，怎么推广？收益怎么看？

先别到处发网址，先做一个别人看得懂的例子

刚建好站，很容易想在每个群里都发一句：“我的 AI 网站上线了，欢迎体验。”

但别人可能还不知道，这和自己有什么关系。

不如换成一个具体问题：一张文章封面怎么做？一段不好读的文案怎么改？有几句歌词，怎么尝试做成一首歌？

建议用“结果 + 操作步骤 + 使用入口”的方式分享。把你实际用过的过程讲清楚，再放网址。没亲自测过的官方案例，就写“官方案例”，不要改成自己的经历。

如果不知道从哪里开始，可以在官方创收联盟的 “获客与增长 → 推广素材库”里找短文案、长文章和配图。使用前检查模型、价格和链接是否仍然适用，也别把示例图片里别人的二维码当成自己的入口。

分享自己的站之前，先检查客户归属

经营分站时，还要打开 我的分站 → 管理 → 分发设置，核对邀请关系配置。

这里的“默认关系”和“强制关系”不是一回事，强制关系会覆盖推广链接、邀请 Cookie 和默认关系，不建议没看懂说明就直接开启。

最好让一位真正的新用户，从全新无痕窗口进入你的站点注册，再到有权限的分销后台检查归属。

已有账号不会因为又登录了你的新站，就自动重新绑定为你的客户。

到底什么时候会有佣金？

可以把过程理解成：

新用户注册并建立邀请关系 → 完成符合规则的充值或购买 → 订单达到完成状态 → 后台生成分销记录。

点击网址、注册账号，本身都不产生佣金；客户每生成一张图片，也不是单独再返一笔推广佣金。佣金来自符合规则的已完成充值或购买订单。

所以，“自动”的是符合条件后由系统生成分销记录，不是建好网站就不用管了。把人带进来、教会他们使用、处理售后问题，这些仍需要你来做。

比例是多少？可以先算一笔简单的账

官方佣金规则页在本文整理时列出的基础等级比例为 10%～24%，但这不是人人固定拿到的比例。实际还可能涉及上下级分成或适用加成，应以自己后台显示的实际比例为准。

只为方便理解，假设：

  • 某笔订单最终被认定的有效计佣金额是 100 美元；
  • 你当时的实际适用比例是 10%；
  • 没有其他调整项。

那么这笔示例佣金就是 100 × 10% = 10 美元。

这不是预测收入。退款、风控、订单状态及当时规则，都可能影响实际记录。最终可用金额、提现方式和处理时间，也要看后台与适用政策；当前规则页提示，需要提现协助时联系平台客服。

另外，再强调一下前面容易混淆的地方：你设置的渠道加价，和你拿到的分销收益，是两件事。

不能直接把“客户售价减平台价”当作自己的收入。白牌客户的收益仍要按有效订单、邀请关系和分销规则核对。具体可参考客户归属、加价与分销收益。

发出去以后，重点看三件事

建议先别盯着每天赚了多少，而是依次确认：

  1. 有人用吗？ 分享的内容有没有解决真实需求？
  2. 能用明白吗？ 新用户是不是卡在登录、选工具或理解价格？
  3. 记录对得上吗？ 客户归属、有效订单和佣金记录是否符合预期？

前两件事做顺了，再考虑增加内容和渠道。发到社区或社群时，也要遵守对方的推广规则，涉及邀请佣金就如实说明。

五、最后：先做一个自己也愿意用的网站

回头看，起步其实不复杂：先注册账号、了解创收联盟，再创建一个 Studio 分站。

接下来换上名字和 Logo，挑几项熟悉的工具，把介绍和客服写清楚。有需要，再绑定自己的域名、补充教程和推荐内容。

平台提供现成的产品和底层技术能力，你把时间放在网站配置、内容、推广和客户服务上。不过，“后端交给平台”不等于所有事情都不用管，也不代表所有使用成本由平台承担。

还有一个边界值得提前知道：分站是自己的品牌入口，不是买断一套软件，也不是单独的一套用户库。账号、余额和套餐仍使用共享体系，部分认证过程和生成文件链接也可能保留公共服务地址。更多说明见白牌边界与上线检查。

如果这些安排符合你的需要，就不用等所有东西都准备得特别漂亮。

先把网站打开，自己用一次，再找几位确实有需要的人试试。哪里不好懂，就改介绍；哪个功能用得多，就把它放前面。

先让它成为一个好用的网站，再慢慢把它做成一项有人愿意持续使用的服务。
