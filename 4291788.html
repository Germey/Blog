暗场最容易暴露 AI 画质短板：Ace Data Cloud GPT Image 2.5 上线 XHigh 与 Max

作者 崔庆才 发表于 2026-11-01 分类于 人工智能 阅读次数： 本文字数： 4.5k 阅读时长 ≈ 4 分钟
Ace Data Cloud GPT Image 2.5 新增 XHigh 与 Max 质量档位。我们以复杂科幻灾难暗场为例，对比 Low、Medium、High、XHigh 与 Max，观察高质量输出如何保留阴影中的人物、建筑、机械、烟雾与反射细节。

做视频时，最难生成的往往不是明亮、干净的产品图，而是夜景、灾难、科幻、战争这类暗色画面。

这类镜头看起来“黑”，实际包含的信息一点也不少。

云层里要有不同深度的亮度变化，烟雾不能糊成一团，远处建筑要保持空间层次，火焰和能量光源需要照亮周围环境，雨水、金属与积水还要形成合理的反射。人物穿着深色服装时，轮廓既不能消失在背景里，也不能像贴纸一样浮在画面上。

质量不足的图片，缩小时可能很有气氛，一旦进入视频制作流程，问题就会迅速暴露。暗部出现色块，建筑细节互相粘连，烟雾失去层次，飞行器结构模糊，人物和背景无法分离。做镜头推进、局部放大、视差动画或图生视频时，这些缺陷还会被进一步放大。

对于影视创作者来说，图片不是生成出来就结束了。它还要进入剪辑、运镜、特效和动画流程。这正是更高质量档位存在的意义。

Ace Data Cloud 的 GPT Image 2.5 现已在 low、medium 和 high 之外，增加 xhigh 与 max 两档质量。Flare 和 Sunburst 均支持这两个档位，包括对应的官方通道。

当画面涉及复杂暗部、体积云、烟雾、火光、雨夜反射和多层空间关系时，创作者可以让模型投入更多生成预算，尽可能保留暗色环境里的结构与细节。

我们用一个高难度暗场测试了五档质量

为了让差异更容易暴露，这次没有选择明亮背景或简单产品，而是设计了一张科幻灾难电影的视觉特效关键帧。

画面发生在蓝调时刻的未来海滨城市。断裂的轨道环悬在城市上空，能量裂缝撕开暴风云层，燃烧的飞船残骸坠向摩天大楼。前景是一名背对镜头的救援飞行员，旁边停着受损的倾转旋翼飞行器。

整个场景以深蓝、黑色和灰色为主，只有能量裂缝、火焰、城市灯光和飞行器局部形成暖色高光。

这种场景会同时考验暗部有没有真实细节，前景人物能否和背景分离，云层和烟雾是否具有空间层次，火焰是否真正照亮周围环境，以及城市、飞行器和轨道环的结构是否连贯。

测试使用更偏向高保真与精细控制的 gpt-image-2.5-sunburst。所有画面采用完全相同的提示词，只改变 quality。

完整测试提示词

这段提示词有意加入了大量容易在暗场中失控的内容：深色云层与多层烟雾、点状火花和燃烧残骸、深色装甲人物、夜间城市建筑、湿润表面与复杂反射，以及多个亮度差异很大的光源。

如果生成质量不足，模型很容易只保留强烈的蓝橙色氛围，却牺牲真正决定画面质感的暗部结构。

Low：氛围很快建立，但更像前期概念草图

low 用约 25.11 秒完成生成，图像输出为 157 Tokens。

它可以快速建立完整场景，也能表现灾难氛围、人物位置和主要光源。用来判断构图是否成立，或者在前期探索多个镜头方向，效率很高。

但在复杂暗场中，我们不能只看画面是否“够黑、够酷”。更重要的是检查阴影里还有没有东西。

救援飞行员的装甲结构、受损飞行器的机械细节、远处建筑之间的边界，以及云层内部的亮度变化，都决定了这张图片能否继续用于后期制作。如果这些内容在原图里已经混在一起，后期单纯提高亮度或锐化，并不能真正找回缺失的结构。

Medium：暗部开始拥有更多可以辨认的内容

medium 用约 27.18 秒完成生成，图像输出为 367 Tokens。

相比 Low，它并没有大幅增加等待时间，但模型获得了更多生成预算。

对于普通视频配图，Medium 已经是一个比较实用的起点。它不仅要完成整体氛围，还需要更认真地处理建筑、载具、人物与环境之间的关系。

在暗色画面里，所谓质量提升并不一定表现为“更亮”或“更锐”。更重要的是，阴影中的结构是否还能被看见，烟雾有没有前后层次，远处城市是否能够形成真实的大气透视，人物是否通过轮廓光自然地从背景中分离出来。

High：从“有氛围”走向“有结构”

high 的生成时间约为 41.35 秒，图像输出增加到 1,413 Tokens。

从这一档开始，模型投入出现了明显跃升。对于影视暗场来说，这些额外投入最值得关注的地方，是亮部与暗部之间的过渡。

能量裂缝不能只是一条白色高光，它应该影响周围云层；燃烧残骸不能只是橙色斑点，它应该产生烟雾、余烬和环境光；积水也不能只是简单镜面，它需要根据屋顶结构和光源方向形成不同强度的反射。

当这些关系更加完整时，画面才会从一张气氛图逐渐接近电影镜头。High 更适合正式进入视频时间线，尤其适合需要轻度推进、平移和景深处理的镜头。

XHigh：为放大、运镜和后期分层保留余量

xhigh 用约 53.68 秒完成生成，图像输出达到 2,511 Tokens。

在视频工作流中，很多问题只有让画面动起来以后才会出现。镜头向前推进时，远处城市需要承受放大；制作视差动画时，前景人物、飞行器和背景需要有清晰边界；交给图生视频模型继续生成时，机械结构和环境关系也必须足够明确，否则运动过程中很容易发生变形。

XHigh 的价值就在这里。它不只是让画面在第一眼看起来更漂亮，而是尽可能为后续制作留下更多可用信息。对于暗色场景来说，这意味着更清楚的轮廓、更稳定的局部结构，以及更有层次的阴影和烟雾。

如果图片要作为重点镜头、片头画面、电影概念图或图生视频的首帧，XHigh 会比普通质量档更符合实际制作需求。

Max：为最重要的暗场镜头拉高输出上限

max 用约 104.43 秒完成生成，图像输出达到 5,650 Tokens。

它的等待时间接近 XHigh 的两倍，图像输出 Tokens 也超过 XHigh 的两倍。这说明 Max 并不是换了一个听起来更高级的名字，而是明显提高了生成投入。

在复杂暗场中，最高质量的意义不是无休止地增加纹理，而是尽可能同时守住多个容易冲突的目标：画面要保持黑暗氛围，但不能丢失结构；能量裂缝要足够明亮，但不能破坏云层细节；人物要清楚，却不能像被单独抠出来；烟雾要丰富，但不能遮住所有建筑；反射要明显，同时又要符合环境光线。

这些要求单独完成并不困难，难的是同时成立。

Max 更适合已经确定构图和提示词之后的最终输出，例如片头主视觉、电影海报、核心镜头、重点宣传素材，以及需要继续进入复杂后期流程的图片。

暗色画面的质量差异，不能只看“清不清晰”

这次测试记录如下：

质量档位 生成耗时 图像输出 Tokens 总 Tokens
Low 25.11 秒 157 567
Medium 27.18 秒 367 777
High 41.35 秒 1,413 1,823
XHigh 53.68 秒 2,511 2,921
Max 104.43 秒 5,650 6,060

从 Low 到 Max，真正需要比较的并不是哪张图单纯更锐利，而是暗色环境里保留了多少有效信息。

可以重点观察救援飞行员的装甲是否有可以辨认的结构，人物与飞行器之间是否存在清晰的空间关系，飞行器的机翼、旋翼和机身是否连贯，远处城市有没有因为黑暗而糊成一整片，云层是否具有前后深度，以及屋顶积水能否反映环境中的多个光源。

暗场最怕的不是黑，而是“黑得没有内容”。

一张高质量的暗色图片，即使整体亮度很低，人物、建筑、机械、烟雾和云层依然应该拥有各自的层次。观众未必会明确说出这些差异，但会直观感受到画面是否具有电影质感。

图片质量决定了视频后期还有多少操作空间

视频创作很少直接使用一张完全静止的原图。

创作者通常会进行镜头推进、横向移动、局部裁切、前后景分层、光效叠加、景深模拟，或者把图片交给图生视频模型继续生成。这些操作都会放大暗部缺陷。

如果人物轮廓本来就和背景粘在一起，制作视差时会很难分层；如果建筑结构已经模糊，镜头推进后只会看到更大的模糊；如果烟雾没有空间关系，生成动态效果时就容易变成无规律的翻滚色块。

因此，更高质量的原始图片并不只是“成片看起来更漂亮”，它还直接决定了后期制作能够走多远。

不必每一张都用 Max，但重要暗场值得更高质量

合理的制作方式，不是从第一张草图开始就把质量开到最高。

探索阶段可以使用 Low 或 Medium，快速确认构图、角色位置、光源方向和整体色调。方向稳定以后，可以用 High 生成正式素材。如果画面需要明显放大、复杂分层或继续生成视频，XHigh 会更合适。

Max 则应该留给最重要的镜头，例如片头第一帧、海报主视觉、预告片核心画面，或者决定整条视频质感的关键场景。

Ace Data Cloud 为 GPT Image 2.5 加入 XHigh 与 Max，真正带来的不是多了两个参数，而是让创作者面对复杂暗场时，不必停留在“气氛差不多”的阶段。

黑暗不再意味着放弃细节。

当模型拥有更高的质量预算，阴影里的城市、人物、飞行器、烟雾和反射才有机会一起被保留下来。对于影视创作而言，这些藏在暗部里的信息，往往正是画面从普通配图走向电影镜头的关键。
